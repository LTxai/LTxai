<details>
<summary><b>📐 O que é SDD?</b></summary>
<br/>

**Spec-Driven Development** é desenvolver a partir de uma especificação clara: primeiro a spec (o quê e o porquê), depois o plano, as tarefas e só então o código. Funciona muito bem junto com **LLMs**, porque a spec vira o contrato que guia a IA e deixa o resultado previsível e revisável.

</details>
